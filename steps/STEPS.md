# Project Creation Steps: EcoFuture NGO Website

This file logs the steps we took to build this website. It is designed to help you understand the building process manually.

## Step 1: Project Initialization

1. **Initialize Git**: We started by running `git init` in our empty project folder to enable version control. This allows us to track all our changes and revert if needed.
2. **Create Vite App**: We used Vite, a modern and fast build tool, to scaffold a React application. The command used was `npx create-vite@latest . --template react`. This created the basic folder structure, configurations, and boilerplate code for our React app directly in the current folder.
3. **Install Dependencies**: We ran `npm install` to download all the required packages (like React itself) specified in the `package.json` file generated by Vite.

*Git Commit*: `Initial commit: Project scaffold with Vite and React`

## Step 2: Global Styling and Icons

1. **Install Icons**: We installed `lucide-react` by running `npm install lucide-react` to get beautiful, modern icons for our website.
2. **Global CSS**: We updated `src/index.css` to include custom properties (variables) for our colors, gradients, and animations. This gives the site a premium, glassmorphic look.

## Step 3: Building Page Sections

We broke the website down into reusable React components inside the `src/components` folder:
1. **Navbar.jsx**: Creates a sticky, glass-like navigation bar at the top of the screen.
2. **Hero.jsx**: The main welcome section (Homepage) with a strong call-to-action and visually striking layout.
3. **About.jsx**: Highlights the NGO's mission using a grid of informative cards.
4. **Services.jsx**: Displays the impact areas (Reforestation, Ocean Cleanup, etc.) with hover animations on images.
5. **Footer.jsx**: The bottom section of the page.

## Step 4: Assembling the Application

We updated `src/App.jsx` to import and render all these components in order. This forms our complete Single Page Application (SPA).

*Git Commit*: `feat: Add core layout and page sections (Navbar, Hero, About, Services, Footer)`

## Step 5: Adding a Contact Section

We created a `src/components/Contact.jsx` file to serve as our "Contact Page" section. This component includes:
1. Contact information (Email, Phone, Address).
2. A user-friendly contact form to collect messages.

We then imported and added `<Contact />` into `src/App.jsx` right before the footer. Since the "Join Us" button in the Navbar already points to `href="#contact"`, clicking the button automatically scrolls the user down to this new contact page!

*Git Commit*: `feat: Add Contact section and wire up Join Us button`
