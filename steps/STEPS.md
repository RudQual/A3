# Project Creation Steps: EcoFuture NGO Website

This file logs the steps we took to build this website. It is designed to help you understand the building process manually.

## Step 1: Project Initialization

1. **Initialize Git**: We started by running `git init` in our empty project folder to enable version control. This allows us to track all our changes and revert if needed.
2. **Create Vite App**: We used Vite, a modern and fast build tool, to scaffold a React application. The command used was `npx create-vite@latest . --template react`. This created the basic folder structure, configurations, and boilerplate code for our React app directly in the current folder.
3. **Install Dependencies**: We ran `npm install` to download all the required packages (like React itself) specified in the `package.json` file generated by Vite.

*Git Commit*: `Initial commit: Project scaffold with Vite and React`
